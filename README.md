# Shoply

**Shoply** is a full-stack e-commerce application designed to provide a seamless shopping experience for users while offering powerful management tools for administrators. Built with a React frontend and an Express backend, Shoply incorporates modern technologies and best practices for security and performance.

## Features

- **Secure Authentication**: Robust authentication system with role-based access control. Administrators can manage users and orders, while users have access to profile management and order tracking.
- **Product Browsing**: User-friendly interface for browsing products, adding items to the cart, and managing orders.
- **Order Management**: Administrators can efficiently view, process, and fulfill orders with elevated privileges.

## Technologies Used

### Frontend

- **React**: A JavaScript library for building user interfaces.
- **React Router**: For navigation and routing.
- **Formik & Yup**: For form management and validation.
- **Bootstrap & React-Bootstrap**: For responsive design and UI components.
- **Axios**: For making HTTP requests.
- **Testing Libraries**: Jest, React Testing Library, and User Event for robust testing.

### Backend

- **Express**: A minimal and flexible Node.js web application framework.
- **Mongoose**: An ODM (Object Data Modeling) library for MongoDB and Node.js.
- **Body-Parser**: Middleware for parsing incoming request bodies.
- **CORS**: Middleware for enabling Cross-Origin Resource Sharing.
- **Nodemon**: For automatically restarting the server during development.
